================================================================
CUDA SUBGRAPH PARTITIONING: OVERVIEW & RESULTS
================================================================

FILE OVERVIEW
-------------
- `generate_test_model.py`: Generates a synthetic 79-node ONNX model containing heavy Convolution blocks separated by dynamic `Unique` boundaries.
- `partitioner.py`: Topologically traverses the model to identify rule-based boundaries and slices it into independent CUDA-capturable and eager partitions.
- `benchmark.py`: Orchestrates the partitioned subgraphs in Python using ORT's `IOBinding` to seamlessly pass data on the GPU, avoiding CPU memory overhead.
- `benchmark_native.py`: Attempts to run the unpartitioned models natively in a single C++ ORT session to establish a baseline.
